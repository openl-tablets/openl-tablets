# Math Functions

- **Empty values** — a function of one number, such as `abs`, `sqrt` or `cos`, returns an empty value for an empty
  number. `pow`, `atan2`, `copySign`, `getExponent(x, y)`, `IEEEremainder`, `nextAfter(x, y)` and `scalb` return an
  empty value when either argument is empty, and `round`, `quotient`, `mod`, `floorDiv` and `remainder` return one for
  an empty number. `isNaN` and `isInfinite` return `false` for an empty value. A value of a primitive type, such as
  `double`, is never empty: it is `0` until it is set.
- **Number types** — `abs` returns a number of the type of its argument. The other functions compute in `Double`, and
  the variants for `Float` keep the precision of a `Float`.
