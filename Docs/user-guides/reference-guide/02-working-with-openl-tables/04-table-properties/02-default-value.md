#### Default Value

Some properties can have default values. A **default value** is a predefined value that can be changed only in the OpenL Tablets configuration. The default value is used if no property value is defined in the rule table or in the **Properties** table.

Properties defined by default are not added to the table's properties section. To override a default value for a table, define the property in the table, for example, in the **Table Details** pane of OpenL Studio as described in [OpenL Studio Guide > Editing Default Table Properties](../../../openl-studio/editing-testing.md#editing-default-table-properties).
