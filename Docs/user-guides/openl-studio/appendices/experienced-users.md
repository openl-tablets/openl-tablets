## Appendix C: Access to OpenL Studio for Experienced Users

OpenL Studio configuration example is available at <http://localhost:8080/webstudio/application.properties>.

Internal API documentation for OpenL Studio is available at <http://localhost:8080/webstudio/api-docs>,
and is reachable from the **Help** page. The former address, `rest/api-docs`, still leads there.
