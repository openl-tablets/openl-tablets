## System Requirements

The versions below are the ones that OpenL Tablets is built and tested with. The
[Supported Platforms](https://openl-tablets.github.io/openl-tablets/supported-platforms) page is the authoritative list.

### Operating Systems
- **Linux**: Ubuntu 24.04 LTS
- **macOS**: 15
- **Windows**: 11, Windows Server 2022

### Supported Browsers
- **Firefox**: 140 ESR
- **Chrome**: 145
- **Microsoft Edge**: 145
- **Safari**: 26

### Databases
- **PostgreSQL**: 16.1
- **MariaDB**: 10.6
- **MySQL**: 8.0
- **MS SQL Server**: 2019
- **Azure SQL Database**
- **Oracle**: 19c

### Other Software
- **Java**: 21 or later
- **Application Servers**: Apache Tomcat 10.1, Eclipse Jetty 12.1

### Hardware Requirements

| Resource       | OpenL Studio: minimum | OpenL Studio: recommended | Rule Services: minimum | Rule Services: recommended |
|----------------|-----------------------|---------------------------|------------------------|----------------------------|
| **Memory**     | 2 GB                  | 16 GB                     | 512 MB                 | 1 GB                       |
| **CPU**        | 2 cores               | 4 cores                   | 1                      | 2                          |
| **Disk Space** | 100 MB                | 1 GB                      | 100 MB                 | 500 MB                     |

The recommended resources of OpenL Studio depend on the size of the projects and on the count of concurrent users.
